# Кофе дүкені қосымшасы

React Native және Expo негізінде жасалған қосымша.

Экрандар
1. Кіріспе бет (Onboarding)
2. Басты бет (Home — Шевченко 97,себет, фильтр)
3. Толығырақ бет (Detail — S, M, L өлшемдері)
4. Тапсырыс беті (Order — жеткізу, алып кету, баға есептеу)
5. Жеткізу беті (Delivery)

## Іске қосу
1. npm install
2. $env:NODE_TLS_REJECT_UNAUTHORIZED="0"
3. npx expo start --tunnel

   Қосымшаның негізгі мазмұны мен мүмкіндіктері:

Мекенжай мен бағыт: басты бетте Алматы, Шевченко 97 мекенжайы көрсетіледі және жеткізу осы бағытқа бағдарланады.

Кофе мәзірі: бірнеше кофе түрі (мысалы, Caffe Mocha, Flat White, Caramel Macchiato, Iced Americano, Spanish Latte) горизонтальді тізімде рейтингі мен бағасымен бірге беріледі, ішінен атауы бойынша іздеуге, категорияға бөлуге және сүзгі арқылы баптауға болады.

Өлшем және себет: әр кофенің толық сипаттамасын корып, стакан өлшемін (S, M, L) таңдауға, себетке салуға немесе бірден тапсырыс беругк болады.

Тапсырыс және жеткізу: тапсырысты жеткізу (Deliver) немесе алып кету (Pick Up) түрінде рәсімдеп, жалпы соманы есептеп, курьер мен жеткізу уақыты көрсетілетін бетке өтуге мүмкіндік береді
